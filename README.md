# HB's Enchanting Overhaul [Apotheosis Vanilla+ Adaption]

    Adapts the popular Apotheosis Enchanting mod to Vanilla+, but also expands the bookshelf
    system so the many more shelves and items can be added and interact with each other.
    
    Any block - modded or vanilla, can be configured with json to interact with the enchanting table.
    Some blocks even subtract or set maximums on your Apotheosis stats so you will have to be clever
    about which shelves you use to maximize your stats.
    
    Black listed and muturally exclusive enchants can be set in the common config file.
    
    Note that this mod changes Apotheosis Enchanting completely so do not rely on their wiki's any more.
